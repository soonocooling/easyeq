EasyEq User Guide

EasyEq is a menu bar app that turns math written in plain Korean or English into Unicode math. Example: sqrt 2 times sqrt 3 → √2 × √3

Getting started Modes Keys Writing math Troubleshooting

Getting started

  1. On first launch, EasyEq asks for Accessibility permission. Turn on EasyEqSpike in System Settings → Privacy & Security → Accessibility. You do not need to restart the app.
  2. When the menu bar shows √? or √⌨, EasyEq is ready. √✕ means permission is missing.
  3. Click the menu bar icon to switch modes. EasyEq remembers the last mode you chose.

Modes

Drag mode

Select math in text you have already written, by dragging or double-clicking, and a list of candidates appears next to the selection.

  • Click a candidate or press 1–5 to replace the selection with it.
  • Press Enter to pick the first candidate.
  • Press Esc or 0 to keep the original text. Clicking outside the list or pressing any other key also closes it.
  • Selecting ordinary text or empty space shows nothing.
  • By default the list appears only when you select text in an editable field (a chat box, a document, a text field). Selecting read-only text, such as a web page or a message you received, shows nothing.
  • To use drag mode on read-only text as well, turn off 드래그: 입력 칸에서만 띄우기 (Drag: editable fields only) in the menu.

Live typing mode

While you type, EasyEq watches the text just before the cursor. When it looks like math, a candidate list appears right below the text you are writing. It follows your text and updates as you type, and disappears once you move on to ordinary text.

  • Click a candidate or press ⌥ Option+1–5 to replace only the math you just typed. The rest of the sentence stays as it is.
  • Plain digits would clash with typing numbers, so live mode uses ⌥ with the digit.
  • Press Esc to close the list. It stays closed until you change that expression. The Esc key still reaches the app you are typing in.
  • The quoted line at the top of the list shows exactly what will be replaced. If you type so sqrt 2 times sqrt 3, only sqrt 2 times sqrt 3 is replaced.
  • Some apps do not expose the text being typed. The list does not appear there; use drag mode instead.

If an app does not report where its text is on screen, the list appears just below the input field or near the mouse pointer.

Writing math

Spacing is flexible: sqrt2 times sqrt3 and sqrt 2 times sqrt 3 both work. Upper- and lowercase letters are both recognized. Korean phrases work too; see the Korean guide for the full Korean vocabulary.

  • Only the single character after _ or sub becomes a subscript. Wrap longer subscripts in braces or parentheses: x_ij → xᵢj, x_{ij} → xᵢⱼ
  • A number written right after a letter (x1) is offered as a subscript. Numbers after a multi-letter word (mp3) are left alone, and so are a lone capital letter plus number (A4, F1), which are usually ordinary words. Inside an expression such as A1 + A2, capitals are converted too.
  • With a single digit from 2 to 9, such as x2, both the subscript (x₂) and the power (x²) are offered. The subscript comes first.
  • Characters that have no Unicode subscript form (b, c, d, f, g, q, w, y, z and all capitals) stay as written, e.g. x_b.

Troubleshooting

ProblemWhat to do
Nothing happensIf the menu bar shows √✕, grant Accessibility permission. If a rebuilt app stops responding, remove it from the Accessibility list and add it again.
No candidates for an expressionYou may have selected read-only text (see Drag mode above). It may contain a word EasyEq does not know. Try the forms in the tables above. Selections over 200 characters or spanning several lines are ignored.
The live list never appearsThat app does not expose the text being typed. Switch to drag mode there.
The wrong text was replacedPress ⌘Z, then use 로그 열기 (Open Log) in the menu to see which app it happened in.
What about password fields?Nothing is read while secure input is active.

Privacy

Everything runs on this Mac. The log (~/Library/Logs/EasyEqSpike.log) records only the app name, how text was read, its length and the number of candidates — never the text you select or type. Replacing text briefly uses the clipboard, and the original clipboard contents are restored 0.2 seconds later.
