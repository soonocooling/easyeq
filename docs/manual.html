EasyEq 사용 설명서

한글·영어로 쓴 수식 표현을 유니코드 수식으로 바꿔 주는 메뉴 막대 앱입니다. 예: 루트2 곱하기 루트3 → √2 × √3

시작하기 두 가지 모드 키 정리 설정 수식 쓰는 법 문제 해결

시작하기

  1. EasyEq.app을 실행하면 시작하기 창이 나타납니다. 시스템 설정 열기를 눌러 개인정보 보호 및 보안 → 손쉬운 사용에서 EasyEq를 켜십시오. 허용되는 즉시 창에 표시되며, 앱을 다시 시작할 필요는 없습니다.
  2. 메뉴 막대의 아이콘으로 상태를 확인할 수 있습니다.
  3. 아이콘을 누르면 켜기/끄기, 모드, 출력 형식, 설정, 설명서 메뉴가 나타납니다.

두 가지 모드

두 모드는 메뉴나 설정에서 각각 켜고 끌 수 있으며, 함께 켜 둘 수도 있습니다.

드래그하면 후보 보기

이미 써 둔 글에서 수식 부분을 드래그하거나 더블클릭으로 선택하면, 선택 영역 바로 위에 후보 팝업이 나타납니다.

  • 후보를 클릭하거나 숫자 키 1~5를 누르면 선택한 글이 그 후보로 바뀝니다.
  • ↑ ↓로 후보를 옮기고 Enter로 고를 수 있습니다. 처음에는 첫 번째 후보가 선택되어 있습니다.
  • Tab을 누르면 후보 전체가 유니코드 ↔ LaTeX로 바뀝니다.
  • Esc나 0을 누르면 원래 글을 그대로 둡니다. 팝업 밖을 클릭하거나 다른 키를 눌러도 닫히며, 그 키는 사용 중인 앱에 그대로 전달됩니다.
  • 수식이 아닌 글이나 빈 곳을 드래그하면 팝업이 나타나지 않습니다.
  • 기본적으로 입력 칸(채팅 입력창, 문서 편집 영역, 텍스트 필드 등)에서 드래그했을 때만 팝업이 나타납니다. 웹 페이지 본문이나 받은 메시지처럼 고칠 수 없는 글에는 나타나지 않습니다. 설정의 입력 칸에서 드래그할 때만을 끄면 어디서나 나타납니다.

입력하는 동안 후보 보기 (실시간)

글을 쓰는 동안 커서 바로 앞의 내용이 수식처럼 보이면, 쓰고 있는 글자 바로 아래에 후보 창이 나타납니다. 계속 입력하면 창이 글자를 따라 움직이며 후보가 갱신되고, 수식이 아닌 내용을 쓰기 시작하면 사라집니다.

  • 후보를 클릭하거나 ⌥ Option+1~5를 누르면, 방금 쓴 수식 부분만 그 후보로 바뀝니다. 앞의 문장은 그대로 남습니다.
  • 숫자만 누르면 수식에 숫자를 입력하는 것과 겹치므로, 실시간 모드에서는 ⌥를 함께 누릅니다.
  • Esc를 누르면 창이 닫히고, 그 수식을 고칠 때까지 다시 나타나지 않습니다. Esc 입력은 사용 중인 앱에도 그대로 전달됩니다.
  • 창 맨 위의 따옴표 안에 바뀔 부분이 표시됩니다. 예를 들어 그러면 루트2 곱하기 루트3을 쓰면 루트2 곱하기 루트3만 바뀝니다.
  • 입력 중인 글을 읽을 수 없는 앱에서는 창이 나타나지 않습니다. 그런 앱에서는 드래그를 사용하십시오.

글자의 화면 위치를 알려 주지 않는 앱에서는 입력 칸 바로 아래나 마우스 포인터 근처에 창이 나타납니다.

선택한 글 바로 변환 (⌃⌥E)

자동으로 감지되지 않는 앱에서는 글을 선택한 뒤 ⌃⌥E를 누르십시오. 이 단축키는 읽기 전용 글에서도 동작하며, 그때는 고른 후보를 붙여 넣는 대신 클립보드에 복사하고 “복사됨”을 잠깐 보여 줍니다.

  • _나 아래첨자 뒤의 한 글자만 첨자가 됩니다. 두 글자 이상은 괄호로 묶으십시오. x_ij → xᵢj, x_{ij} → xᵢⱼ

문제 해결

증상해결 방법
아무 반응이 없습니다메뉴 막대 아이콘이 경고(⚠︎) 모양이면 접근성 권한을 켜십시오. 일시정지(⏸) 모양이면 꺼진 상태이므로 ⌃⌥M으로 켜십시오. 새로 빌드한 뒤 반응이 없으면 권한 목록에서 EasyEq를 지웠다가 다시 추가하십시오.
수식인데 후보가 나타나지 않습니다입력 칸이 아닌 곳을 드래그했을 수 있습니다. 이때는 ⌃⌥E를 누르십시오. 지원하지 않는 단어가 섞였을 수도 있으니 위 표의 표현으로 바꿔 보십시오. 200자가 넘거나 여러 줄이면 무시합니다.
실시간 창이 나타나지 않습니다그 앱이 입력 중인 글을 접근성으로 제공하지 않는 경우입니다. 드래그나 ⌃⌥E를 사용하십시오.
단축키가 동작하지 않습니다다른 앱이 같은 조합을 쓰고 있을 수 있습니다. 설정에서 다른 조합으로 바꾸십시오.
특정 앱에서는 동작하지 않게 하고 싶습니다설정의 제외 앱에 추가하십시오.
엉뚱한 부분이 바뀌었습니다⌘Z로 되돌린 뒤, 메뉴의 로그 보기에서 어느 앱에서 생긴 일인지 확인하십시오.
비밀번호 입력 칸에서는 어떻게 됩니까?보안 입력 중에는 아무것도 읽지 않습니다.

개인정보

모든 처리는 이 Mac 안에서만 이루어집니다. 로그(~/Library/Logs/EasyEq.log)에는 앱 이름, 읽기 방식, 글자 수, 후보 개수만 기록되며, 선택하거나 입력한 글 자체는 기록되지 않습니다. 치환할 때 클립보드를 잠시 사용하지만 0.2초 뒤 원래 내용으로 되돌립니다.
